# Authored shelf and planogram drawings

All PNGs are original synthetic drawings generated by `../build_fixtures.py` with Pillow.
They illustrate a shelf-photo workflow but are explicitly labelled drawings, not photographs.
The shared approved planogram and every observation are rendered separately at 600 × 400.
Content-addressed filenames carry no class label. The fixture inputs map each pair to its role;
only the generator holds drawing descriptions, and only labels.jsonl supplies evaluation truth.

The fixed zones represent oats on the left, tea in the center, and soup on the right. Group-level
compliance accepts any positive facing count, variable spacing, and readable alternate packaging.
Empty zones, swapped groups, and mixtures with unknown products are noncompliant. A cart hides
whether a group is present, so that zone needs review. A look-alike uses the oats color but says
`???`; both the synthetic model answer and the color baseline intentionally miss this case.
These examples cannot measure camera robustness, merchandising accuracy, or real inventory.

Rebuild with `python recipes/65-retail-shelf-compliance/build_fixtures.py` from the repository root.
The generator refuses to replace recorded responses without `--force`.
